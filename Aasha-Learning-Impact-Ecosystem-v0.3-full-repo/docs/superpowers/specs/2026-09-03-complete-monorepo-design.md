# Complete Modular Monorepo Design

## Authority
Phase-0 Constitution v1.1 is authoritative. Scope is Class 1–10. The system is school-book-first, human-guided, safe, offline-first and evidence-driven.

## Design
A single modular monorepo contains learner/public/teacher/admin apps; reusable engine packages; content packages; service adapters; database schemas; infrastructure; and tests. Phases activate capability without replacing the architecture.

## Beta posture
Rewards and verification remain in the architecture but do not block learning validation. Centre verification is manual. No uncontrolled child AI chat, child social network, public child leaderboard, mandatory login or payment automation.

## Non-negotiable boundaries
- Game score is not mastery.
- AI is not progression authority.
- Offline learning cannot depend on the backend.
- Content is versioned and provenance-aware.
- Donor/public reporting is aggregate.
