# Phase Gates

Each phase must have runnable tests and a documented exit gate.

- Phase 0: schema/contracts load; learner works offline.
- Phase 1: reusable engines accept data-only chapter packages.
- Phase 2: assessment and TEAS are deterministic and testable.
- Phase 3: visual/simulation adapters are licensable and offline-packable.
- Phase 4: rewards are idempotent; Beta verification remains manual.
- Phase 5: textbook -> production package pipeline validates provenance.
- Phase 6: events sync idempotently after reconnection.
- Phase 7: API authorization and audit boundaries are enforced.
- Phase 8: teacher/admin views expose appropriate aggregates and interventions.
- Phase 9: public reporting never leaks child-level identity.
- Phase 10: automated end-to-end, performance, accessibility, security and recovery checks pass.
