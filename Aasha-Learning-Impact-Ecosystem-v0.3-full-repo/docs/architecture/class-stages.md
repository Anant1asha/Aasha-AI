# Class 1–10 Stage Model

- Foundation: Classes 1–2 — concrete, visual, short interactions, simple vocabulary.
- Primary: Classes 3–5 — guided reasoning, bilingual semantic support, worked examples.
- Middle: Classes 6–8 — abstraction, multi-step reasoning, simulations and misconception remediation.
- Secondary: Classes 9–10 — rigorous models, transfer, exam-aligned reasoning and evidence-backed reflection.

Content may specify stage hints while the runtime chooses presentation complexity within the class boundary.
