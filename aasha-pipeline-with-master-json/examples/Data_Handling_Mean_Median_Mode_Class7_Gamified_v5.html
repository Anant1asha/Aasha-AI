Node 1: Collecting Observations, Tally Marks, and Frequency (प्रेक्षण, मिलान-चिह्न और बारंबारता)

Each numerical value recorded in a survey is called an observation. We organize raw data into a frequency distribution table using tally marks (in bundles of 5) and visualize them using a bar graph or histogram. The Arithmetic mean is the sum of all observations divided by the total number of observations.

Node 3: Mode and Median (बहुलक और माध्यिका)

The mode of a set of observations is the observation that occurs with the highest frequency. When data are arranged in ascending or descending order, the middle observation is called the median, which splits the sorted dataset into two equal halves.
